# HHA Margins - website and demo dashboard

Open `HHA Margins Landing.dc.html` in a browser to start. Keep every file in this folder together; the pages load `support.js` and link to each other by filename.

## Pages
1. HHA Margins Landing.dc.html - home page
2. HHA Margins Services.dc.html - services
3. HHA Margins Pricing.dc.html - Essentials from $499 and Custom
4. HHA Margins About.dc.html - how we work and the team
5. HHA Margins Resources.dc.html - articles
6. HHA Margins Contact.dc.html - margin review form
7. HHA Margins Tour.dc.html - product tour with the live dashboard
8. HHA Margins HIPAA.dc.html - HIPAA compliance
9. HHA Margins Legal.dc.html - privacy and terms (`?terms` opens Terms)
10. HHA Margins 404.dc.html - page not found
11. HHAMargins Dashboard.dc.html - demo dashboard (demo@hhamargins.com / homecare2026)

## Before going live
- Replace phone, email, web address and social links (also in the Google business data on the home page).
- Replace the sample testimonials with real ones.
- Have counsel review Privacy, Terms and the HIPAA page.
- Connect the contact form, newsletter and demo login to real services.
- Point your host's 404 page at HHA Margins 404.dc.html.
